Beschreibung: Bearbeitet das Modul ContactManager, das eine einfache Kontaktverwaltung ermöglicht. Die Kontaktverwaltung soll folgende Funktionen unterstützen
(Die eingabe der Werte muss nicht übers Terminal stattfinden sondern können fest eingetragen werden):

1. hinzufügen eines neuen Kontakts.
2. Entfernen eines Kontakts.
3. Anzeigen aller Kontakte.

Die Namen der zu schreibenden Funktionen sind in der dazugehörigen Testfile definiert.
