Beschreibung: Bearbeitet das Modul SimpleCalculator, das grundlegende mathematische Operationen unterstützt. Der Taschenrechner soll folgende Funktionen unterstützen:

1. Addition zweier Zahlen.
2. Subtraktion zweier Zahlen.
3. Multiplikation zweier Zahlen.
4. Division zweier Zahlen.

Die Namen der zu schreibenden Funktionen sind in der dazugehörigen Testfile definiert.
